# Library Book Management API

## Description
A REST API developed using Node.js and Express.js
to manage library books.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Postman

## Features
- Get all books
- Add a new book
- Get book by ID
- Update book
- Delete book
- Filter books by author

## Installation

```bash
npm install
```

## Run the project

```bash
node server.js
```

Server URL:
http://localhost:3000

## API Base URL
/api/books

## Storage
All book records are stored in an
in-memory JavaScript array.
